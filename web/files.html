Flea, Folio

Each file manager opens a folder of 5000 empty files in its list view, and the Down key is held for 12 seconds on a virtual keyboard: the compositor passes on the one press and the file manager repeats it, about 480 files. On every machine of the lab, in Omarchy's session, under Hypoland and under stock Hyprland 0.57.2. Every cell is Hypoland / Hyprland: green where Hypoland is at least 5% better, red where it is at least 5% worse; a dash where the file manager does not run or there is nothing to count.

File managerVersionWhat it is
Flea0.4.3A keyboard-first file manager for Omarchy, written in Rust with GPUI (the Zed editor's UI toolkit) and drawn on the GPU through wgpu.
Folio0.6.1 (0.7.1 on the MSI Claw)Omarchy's own file manager, written in C++ with Qt Quick.

Medians of 5 to 21 fresh sessions of each per machine, Hypoland 0.4.0 against Hyprland 0.57.2-2, alternating through the night of 2026-11-24. The X200 and the Turbo-X hung in a Hyprland session that night and add the sessions of 11-25. Flea opens no window on those two (it needs more than OpenGL 2.1), where Hyprland runs with Omarchy's GLES 3 override (omarchy#14764). The Mac mini M1 reports no page flips; the Turbo-X's file manager is mostly in swap, so it has no memory cell. Nautilus left Omarchy on 2026-11-13. Raw data: 20261124-all-machines-0.4.0-vs-hyprland-0.57.2, 20261125-x200-turbox-0.4.0-vs-hyprland-0.57.2.

Hypoland: Hyprland for GPUs that stop at OpenGL ES 2.0.

Hypoland is a fork of the Hyprland tiling Wayland compositor with a renderer rewritten for GLES 2.0. It runs a complete desktop on a 2008 ThinkPad X200 at 60 fps, and your Hyprland config, hyprctl and scripts keep working.

why: Hyprland needs OpenGL ES 3.0

Hyprland needs OpenGL ES 3.0. Plenty of laptops that still work fine top out at GLES 2.0, and on them Hyprland does not start at all.

Hypoland keeps the compositor and replaces what the GPU can't do: the renderer and all shaders are GLES 2.0 / GLSL ES 1.00, and the GPU-heavy extras are either gone or off by default. aquamarine, Hyprland's rendering backend library, is modified the same way so that it runs on GLES 2.0, and ships built into Hypoland.

The name: hypo- means "under". The O in the logo is a potato, hanging below the line.

Measured on the test machine running the full Omarchy session (Quickshell bar, wallpaper, notifications). Stock Hyprland 0.56.2 aborts at startup on the same machine. Hypoland's own optimizations for this hardware include drawing straight into the scanout buffer, clearing only damaged areas and double-buffered shm uploads.

lspci: supported GPUs and laptops

  • Intel GMA 4500MHD / GM45 (Gen4.5), the tested target: ThinkPad X200, X200s, X301, T400 and T500
  • Intel GMA X3100 / 965GM (Gen4): ThinkPad X61, X300 and T61 with Intel graphics
  • Desktops with Intel G41, G43, G45 or Q45 chipset graphics (GMA 4500 / X4500), the same generation
  • Other GPUs with OpenGL ES 2.0 under Mesa should work, but are untested

Developed on a ThinkPad X200 with Mesa's crocus driver. Only the X200 is tested.

removed: GPU-heavy features

  • Color management and HDR
  • Motion blur
  • Blur variants other than dual Kawase
  • Plugins and hyprpm
  • Logo background and default wallpapers
  • Hyprland's welcome app, update news and donation popup

Their config options stay registered and are ignored, so your config loads without errors.

changed

  • Blur, shadows, animations and the splash text are off, turn them on if you like
  • XCursor themes instead of hyprcursor
  • quirks:skip_non_kms_dmabuf_formats is off, so transparent clients work on Gen4
  • Windows at 98% opacity or more and the wallpaper are drawn opaque, which saves fill rate
  • Xwayland starts when the first X11 program connects

foot: build from source

# same dependencies as Hyprland, but aquamarine
# is embedded, udis86, glaze and glslang are
# not needed
$ git clone https://github.com/hegjon/hypoland
$ cd hypoland
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j$(nproc)

# or, on Arch: a package that replaces hyprland
$ cd packaging/arch && makepkg -f

README: build notes

See the Hyprland wiki for the dependency list. Hypoland builds aquamarine from its own tree, patched for GLES 2.0, and never uses the system one.

Build on a fast machine and copy the result over? Target baseline x86-64. Do not use -march=native, your desktop CPU knows instructions a Core 2 Duo doesn't.

The Arch package provides and conflicts with hyprland, and ships its own hyprctl so the versions match.

man hypoland: frequently asked questions

Will it run on my GPU?

If Hyprland dies with eglCreateContext failed and eglinfo shows OpenGL ES 2.0 but no 3.0, Hypoland is meant for you. Gen4 Intel is tested; anything else is untested, and reports are welcome.

I have a modern GPU. Should I use it?

No, use Hyprland. It has color management, HDR, plugins and more effects. Hypoland only exists because those machines can't run it.

Does Omarchy work?

Yes. Omarchy 4 is what the test machine runs: the Quickshell bar, notifications, wallpaper, windows and Xwayland all work. Chromium runs, but falls back to software rendering because it wants GLES 3 itself. Floating workspaces have no titlebars: Omarchy draws them with a Hyprland plugin, and Hypoland has no plugins.

Does screen recording work?

Yes, with wf-recorder installed. Omarchy records with gpu-screen-recorder, which does not start on GLES 2 hardware, and falls back to wf-recorder. It encodes on the CPU: the X200 records its 1280x800 screen at about 34 fps.

Can I keep blur?

Yes, dual Kawase blur is kept and costs about 1% CPU on the X200. It is off by default, turn it on in your config. The same goes for shadows, rounding and animations.

Do Hyprland plugins work?

No, and they will not come back. The plugin system was removed on purpose: a plugin has to be built against the exact Hyprland source it loads into, and most plugins draw with GLES 3 renderer code that Hypoland no longer has. hl.plugin.load() warns and does nothing, so configs that load plugins still start. Tools that inject input can use the Wayland protocols instead, zwlr_virtual_pointer_manager_v1 and zwp_virtual_keyboard_manager_v1 are supported (issue #1).

Is this an official Hyprland project?

No. Hypoland is an independent fork, not affiliated with or endorsed by Hyprland or its developers. All credit for the compositor goes to Hyprland and its contributors.

Why aren't these changes part of Hyprland?

The OpenGL ES 2.0 support was offered to Hyprland, and its maintainer declined it: he maintains the code base and does not want it there (discussion). That is his call to make, so the support lives on in this fork instead.
